# Brew Bliss Cafe ☕

**Project Type:** Cafe Website

## About the Project
Brew Bliss Cafe is a responsive cafe website designed to showcase a cafe's menu, special offers, and contact information. It features a warm, coffee-inspired design.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Attractive homepage with a coffee background
- About Us section
- Menu with food and beverage items
- Add to Order buttons
- Interactive cart with item count and total price
- Special Offers section
- Contact information and footer
- Responsive layout for mobile devices

## Purpose
To create a simple, attractive and user-friendly website for a cafe.
